単体試験の書き方（`team/unit-test-guide.md`）の 3.6 の書式。テストコードを書く前にこの表を作り、レビューを受ける。

## 対象

| 項目 | 内容 |

| 対象の関数 | （ファイル名と関数名） |

| 設計書の参照箇所 | （`docs/04-business-rules.md` の節。数値例がある場合はその表） |
| 作成日・作成者 | |

## テストケース

| テストID | 観点ID | 分類 | 前提（fixtures・マスタ） | 入力 | 期待値 | 根拠 |
|---|---|---|---|---|---|---|
| UT-XXX-001 | | | | | | |
| UT-XXX-002 | | | | | | |

| 列 | 書き方 |
|---|---|
| テストID | 手順書 4.2 の規則（`UT-{機能略号}-{連番3桁}`。001 から欠番なし） |
| 観点ID | 手順書 3.4・3.5 の観点ID。複数ある場合はカンマ区切り |
| 分類 | 正常／異常／境界（前・ちょうど・後）／組み合わせ |
| 前提 | 使う fixtures の名前、変えたマスタの値 |
| 入力 | 関数に渡す値のうち、そのケースで意味のある値 |
| 期待値 | 設計書の数値例、または手で計算した値。計算した場合は式も書く |
| 根拠 | 業務ルールID、または 02 のチェックID |
