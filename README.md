# 経費精算システム（EXP）

架空の会社「インフォ商事株式会社」の経費精算システムです。研修・検証用に作成したもので、実在の会社・人物・駅・路線・取引先とは関係ありません。氏名・メールアドレス（`info-shoji.example`）・登録番号（`T0000000000…`）はすべて架空の値です。

| 項目 | 内容 |
|---|---|
| 用途 | 研修・検証用。認証はなく、画面上部のプルダウンで利用者を切り替えて操作します |
| 動作環境 | Windows の Microsoft Edge |
| インストール | 不要。Node.js・Python などは使いません。インターネットに接続しなくても動きます |
| データ | ブラウザ内の SQLite（sql.js）。ブラウザの localStorage に保存します（キーは `info-expense:` で始まる） |
| 設計書 | `docs/` の基本設計書（01〜06）。開発ガイドは `CLAUDE.md`、単体試験の書き方は `team/unit-test-guide.md` |

## 起動方法

1. このフォルダをパソコンに置きます（`git clone` または ZIP をダウンロードして展開）。
2. `index.html` を Microsoft Edge で開きます（エクスプローラーでダブルクリック。既定のブラウザが Edge でない場合は右クリック →「プログラムから開く」→ Microsoft Edge）。
3. 画面上部の「利用者」で操作する社員を選びます。

初期データの業務日付は 2026-11-30 です。端末の日付に関係なく、いつ開いても同じ状態から始まります。

## テストの実行方法

単体試験の対象は `js/core/` と `js/logic/` です（DB・画面は使いません）。

| 方法 | 手順 | 結果の見方 |
|---|---|---|
| Edge で見る | `tests\test.html` を Edge で開く | タブの題名が `PASS 件数/件数` なら全件合格。URL の末尾に `?filter=RCP` を付けると絞り込み |
| PowerShell | このフォルダで `powershell -ExecutionPolicy Bypass -File tests\run-tests.ps1` | `FAIL` の行と最後の `SUMMARY` を表示。全件合格なら終了コード 0。絞り込みは `-Filter RCP` |

テストを追加したら `tests\test.html` に `<script>` を1行追加します。書き方は `team/unit-test-guide.md` に従います。

## フォルダ構成

```
index.html      画面（全画面の入れ物）
css/            スタイル
js/lib/         sql.js 1.10.3（変更しない）
js/core/        名前空間・設定・メッセージ・日付・CSV
js/logic/       業務ロジック（単体試験の対象）
js/data/        DDL・初期データ・DB 管理・リポジトリ
js/service/     操作ごとの処理
js/batch/       バッチ B01〜B05
js/ui/          ルーター・共通ヘッダ・画面部品
js/screens/     画面 SCR-01〜SCR-09
tests/          単体試験
samples/hr/     人事マスタ取込ファイルの例
docs/           基本設計書
team/           開発チームの手順書
```

詳しくは `CLAUDE.md` と `docs/06-architecture.md` を参照してください。
